# Continue on your laptop

1. In GitHub Desktop, sign in as `itsEkramah`.
2. Choose File > Clone repository > URL, then enter `https://github.com/itsEkramah/reviewflow-automation`.
3. Choose a project folder and clone it. If already cloned, use Fetch origin and Pull origin after publication.
4. In the ChatGPT desktop app, add the cloned folder as a local project. Make it the primary folder for this project.
5. Start a Codex chat with **This computer** selected, and ask it to read AGENTS.md, install dependencies in a virtual environment and run the README commands.
6. Review edits and tests; use GitHub Desktop to commit and push changes. Pull before working on another laptop.

You do not need a personal access token in the chat. Keep credentials out of code. A browser-connected chat does not automatically gain access to the clone on your disk.

The default demo needs no hosting account or paid API key. ReviewFlow live AI mode is optional and has separate server-side configuration.

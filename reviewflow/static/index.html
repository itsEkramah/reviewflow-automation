Turn incoming requests into a review queue. Inspect, edit and approve a response before it goes anywhere.

01 / Incoming request

Reusing the same ID and message returns the existing ticket. A changed message needs a new ID.

How this demo works

  1. Validate and classify the incoming message.
  2. Store a structured draft in SQLite.
  3. A human edits the draft and approves or rejects it.
  4. Record the decision in the event log.

Approval records a decision only. This app has no email, CRM or messaging send integration.
